# example-elysia-vite

Example full-stack app pairing an Elysia API server with a Vite front end.

## Usage

```bash
bun install
bun run dev
```

The root scripts use Bun workspaces to start the client and server together. `bun run build` builds both packages.

## Layout

- `client/` — Vite front end
- `server/` — Elysia API
